# 腾讯云cos 加密上传
主要打算实现两个功能，一个就是一个上传功能，一个就是解密功能
## 要求目标
- 这个文件云端是无法知道这个数据是什么
- 这个代码我要考虑到通用性这个功能，就是多端都是可以使用的，例如web，移动端，mac或者pc端

## 语言选择
C++ 17 通用性 那肯定c++了

## 加密算法选择
**AES-256-GCM**
- AEAD对称加密算法，提供加密和完整性验证
- 确保数据机密性和完整性
- 云端无法查看实际内容
- 广泛支持，跨平台兼容性好

## 核心功能
### 1. 加密上传
- 本地文件进行AES-256-GCM加密
- 生成随机IV和认证标签
- 加密数据上传到腾讯云COS
- 云端存储加密后的数据和元信息

### 2. 解密下载
- 从云端下载加密数据
- 使用本地密钥进行解密
- 验证数据完整性
- 恢复原始文件内容

## 快速开始
### 编译
```bash
mkdir build && cd build
cmake ..
make
```

### 基本使用
```cpp
#include "crypto.h"

// 初始化密钥（256位）
unsigned char key[32] = {/* 你的密钥 */};

// 加密文件
encrypt_file("input.txt", "input.txt.enc", key);

// 解密文件
decrypt_file("input.txt.enc", "output.txt", key);
```

## 安全性考虑
- 密钥管理：采用安全的密钥存储和管理机制
- 随机数：使用密码学安全的随机数生成器生成IV
- 完整性：使用GCM模式的认证标签验证数据完整性
- 云端隐私：加密后的数据云端无法查看内容
